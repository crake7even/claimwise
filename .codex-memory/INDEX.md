# Codex 项目记忆索引

本目录用于保存保险资料智能问答系统的长期项目记忆。索引只放简短说明，细节按需读取。

## 记忆文件

- `project-overview.md`：项目背景、技术栈、目录结构、核心能力。开始理解项目时读取。
- `decisions.md`：关键技术决策和取舍。修改架构、接口、UI 命名时读取。
- `commands.md`：启动、构建、验证命令。运行或排查项目时读取。
- `debug-history.md`：已踩过的坑和排错经验。遇到 ES、API、编码、端口问题时读取。
- `session-handoff.md`：最近一次工作状态和下一步建议。新对话继续任务时优先读取。

## 使用规则

- 不要在记忆文件中写入 API Key、密码、Token、私钥或数据库凭据。
- 只记录敏感配置所在位置，例如 `backend\.env`。
- 更新记忆前先展示草案，用户确认后再写入。
- 定期清理过期、重复或互相矛盾的记忆。
