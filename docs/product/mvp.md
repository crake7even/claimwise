# MVP

## MVP 目标

当前 MVP 是一个本地可运行的保险资料智能问答系统，用于验证：

- 能否基于本地保险资料进行问答。
- 能否在同一聊天界面中切换不同检索模式。
- 能否通过前后端分离方式完成流式回答体验。

## 核心用户场景

- 用户围绕保险产品、保障范围、理赔流程、投保要求等内容提问。
- 系统优先从本地保险资料中召回相关片段。
- 本地资料不足时，`联网搜索` 模式可补充外部搜索结果。
- 用户在前端页面查看流式生成的中文回答。

## MVP 功能范围

- React/Vite 前端聊天界面。
- FastAPI 后端接口：
  - `GET /api/health`
  - `POST /api/chat`
- 三种前端模式：
  - `快速检索`
  - `语义理解`
  - `联网搜索`
- 三种后端模式值：
  - `quick`
  - `semantic`
  - `web`
- 本地资料目录：`backend/docs`。
- Qwen/DashScope、Elasticsearch、Tavily 按本机配置启用或降级。

## 暂不做

- 不新增用户账号、权限或管理后台。
- 不新增线上部署流程。
- 不改变现有保险资料库路径。
- 不改变现有 API 请求体和响应方式。
- 不扩展未确认的新业务功能。

## 验收标准

- 后端启动后 `/api/health` 可访问。
- 前端启动后可访问 `http://127.0.0.1:3000/`。
- 三种模式均可发起问答请求。
- 未配置某些外部服务时，系统按现有降级逻辑运行。
- 前端 `npm run lint` 和 `npm run build` 通过。
